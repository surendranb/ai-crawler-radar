# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `ai-crawler-radar`, please report it privately:

1. **Email**: reachsuren@gmail.com
2. Include reproduction steps, relevant URL payloads, and environment details.
3. Please do not open public GitHub issues for security vulnerabilities.

We take security seriously and will acknowledge reports within 48 hours.
